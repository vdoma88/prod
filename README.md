# Лендинг «Сила Рода»

Файлы:
- `index.html` — разметка лендинга
- `styles.css` — адаптивные стили
- `tree.js` — интерактивное золотое Древо Рода на Three.js
- `assets/` — подготовленные из предоставленного референса декоративные изображения

## Запуск
Из папки проекта:

```bash
python -m http.server 8080
```

Открыть: `http://localhost:8080`

Three.js загружается с CDN. Если нужен полностью автономный/offline-вариант, скачайте `three.min.js` локально и замените CDN-путь в `index.html`.

Перед публикацией замените `hello@example.com` в CTA на нужный Telegram / форму / email.
