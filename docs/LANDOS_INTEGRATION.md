# Интеграция vdoma88/landos → vdoma88/prod

## Статус

Лендинг «Сила Рода» встроен в `prod/site/`.

Зафиксированная исходная точка переноса:

- источник: `vdoma88/landos`
- commit: `7bd06b90367b9a33a5188463d4c9ee72f2c87aa8`
- состояние источника: финальный QA — mobile/readability/accessibility/Telegram/tree.js

`vdoma88/prod` является каноническим репозиторием для дальнейшей разработки
лендинга и его продакшен-интеграции.

## Что перенесено и сохранено

Из `landos` в `site/` сохранены:

- главная страница и premium-дизайн;
- 8 исходных направлений:
  - Связь с Родом;
  - Мистерия «Сила Рода»;
  - Игра «Сила Рода»;
  - Подношения духам предков;
  - Свечные практики;
  - Карты Таро;
  - Огненный массаж;
  - Индивидуальные консультации;
- адаптивность и iOS safe-area;
- окно заявки и Telegram-flow;
- `tree.js` и его low-power / reduced-motion поведение;
- SEO-метаданные, favicon, manifest, 404;
- мобильная навигация, FAQ и accessibility-доработки.

## Что добавлено только в prod и должно быть сохранено

Поверх исходного лендинга `prod` содержит функции, которых нет в `landos`:

- `courses.html` — единая страница «Мои курсы»;
- `runes.html` — Руны;
- ссылки входа в учебные кабинеты:
  - `plamya.belayarod.ru`;
  - `rod.belayarod.ru`;
  - `taro.belayarod.ru`;
  - `runes.belayarod.ru`;
- общий бренд в `brand/`;
- прямой Telegram Екатерины `@BelayaKatrin`;
- canonical / OG URL для `https://belayarod.ru`;
- PWA-совместимость со старой иконкой школы «Язык Пламени»;
- сборка `site/ + brand/ → dist/`;
- nginx/VPS/SSL/миграционная инфраструктура.

Поэтому нельзя заменять `prod/site/` прямой копией `landos`: такая операция
удалит продакшен-расширения. Изменения из старого репозитория, если они когда-либо
понадобятся, нужно переносить как выборочный merge.

## Проверка работоспособности

Перед публикацией:

```bash
npm run test
npm run test:e2e
```

`npm run test` проверяет:

- наличие ядра перенесённого лендинга;
- все локальные ссылки и изображения;
- все курсы и ссылки входа;
- одинаковый список направлений в формах заявки;
- Telegram-only сценарий;
- CSP-совместимость;
- синтаксис JavaScript;
- согласованность версии общего бренда.

`test:e2e` дополнительно открывает страницы в Chromium на desktop и mobile,
проверяет отсутствие горизонтального overflow и работу общей навигации.

## Правило дальнейшей работы

Все дальнейшие изменения лендинга выполняются в:

```text
vdoma88/prod/site/
```

Общие компоненты курсов — в:

```text
vdoma88/prod/brand/
```

Серверная инфраструктура — в:

```text
vdoma88/prod/infra/
```

Это позволяет развивать лендинг, курсы и инфраструктуру в одном репозитории,
не теряя работоспособность уже подключённых приложений.
