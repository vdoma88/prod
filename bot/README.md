# Telegram-бот лендинга «Сила Рода»

Автоворонка для новых людей с belayarod.ru. Человек открывает бота по ссылке
с сайта и выбирает, с чем пришёл. Бот рассказывает о подходящем формате и
принимает заявку, а заявка сразу приходит Екатерине. Если человек заявку не
оставил, бот пришлёт три спокойных сообщения через 1, 3 и 7 дней и после
этого больше не напоминает.

Это отдельный бот. `/tg/ekaterina-bot/` (обряды) он не трогает.

## Как это выглядит для человека

1. `/start` — приветствие и пять кнопок-запросов, как в блоке «Выберите по
   своему запросу» на главной.
2. Выбор запроса — короткое описание формата и кнопки «Хочу записаться»,
   «Подробнее на сайте», «Другой запрос».
3. «Хочу записаться» или любое сообщение боту — заявка уходит Екатерине,
   серия напоминаний останавливается.
4. `/stop` — бот больше не пишет. Если человек заблокировал бота, серия
   останавливается сама.

Сообщения серии не приходят ночью: всё, что выпадает на время с 21:00 до
10:00 по Москве, переносится на 10:00.

## Для Екатерины

- Заявка приходит ей в Telegram: имя, @username, выбранное направление,
  сообщение человека.
- Чтобы ответить человеку без @username, достаточно ответить (reply) на
  уведомление — бот перешлёт текст.
- `/stats` — сколько человек сейчас в серии, сколько оставили заявку и
  сколько отписались.

## Тексты

Все тексты лежат в `messages.mjs`. Сейчас это **черновик по тону лендинга**,
его нужно вычитать. Код менять не нужно: достаточно поправить строки и
перезапустить службу (`sudo systemctl restart rodbot`). Там же настраиваются
задержки серии (`afterHours`).

## Установка на сервер

```bash
sudo bash /var/www/prod/infra/vps/14-bot.sh
```

Первый запуск создаёт пользователя `rodbot` и файл `/etc/rodbot.env` с
секретами, затем просит токен:

1. В Telegram: @BotFather → `/newbot` → скопировать токен.
2. Вписать токен в `/etc/rodbot.env` (`TELEGRAM_BOT_TOKEN=...`).
3. Запустить скрипт ещё раз. Он поднимет службу, подключит nginx и сам
   зарегистрирует вебхук.

В конце скрипт покажет ссылку для привязки Екатерины
(`t.me/<бот>?start=admin-<код>`). Её нужно один раз открыть в её Telegram,
после этого заявки начнут приходить. Можно привязать несколько человек.

Ссылка для сайта: `https://t.me/<бот>?start=landing`. Слово после `start=`
сохраняется как источник, поэтому для разных кнопок можно давать разные
метки: `start=therapy`, `start=courses`.

## Уведомления из курсов

Когда в любом из курсов ученица сдаёт домашнее задание, проходит проверку
или пишет куратору, Екатерине в этот же чат приходит, например,
«📝 Новое ДЗ на проверку · Таро — Анна — Глава 3» с кнопкой «Открыть».
Ночью (21:00–10:00 МСК) — без звука.

Курсы живут на том же сервере и шлют событие на внутренний адрес:

```
POST http://127.0.0.1:4310/tg/rod-bot/notify
X-Notify-Secret: <NOTIFY_SECRET>
{"course": "runes", "kind": "test", "student": "Анна", "item": "Модуль 2: 4 из 5", "url": "https://runes.belayarod.ru/…"}
```

- `kind` — `homework` (по умолчанию), `test` или `message` (заголовки —
  `EVENTS` в `messages.mjs`).
- `course` — `rod`, `plamya`, `taro` или `runes` (названия — `COURSES` в
  `messages.mjs`); `url` — только `https://….belayarod.ru/…`, иначе кнопки нет.
- Снаружи адрес недоступен: nginx пропускает только точный `/tg/rod-bot`,
  а сам бот принимает `/notify` лишь с `127.0.0.1` и с верным секретом.
  Без `NOTIFY_SECRET` адрес выключен (503).
- В курсе достаточно вписать в его `.env` `ROD_NOTIFY_SECRET=` — тот же
  секрет из `/etc/rodbot.env` — и перезапустить курс. Без него курс просто
  не шлёт уведомления, остальное работает как раньше.

## Переменные (`/etc/rodbot.env`)

| Имя | Что |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `WEBHOOK_SECRET` | секрет вебхука, генерируется скриптом |
| `ADMIN_CODE` | код привязки Екатерины, генерируется скриптом |
| `NOTIFY_SECRET` | секрет для уведомлений из курсов, генерируется скриптом |
| `ADMIN_CHAT_IDS` | необязательно: id чатов админов через запятую |
| `PUBLIC_URL` | адрес вебхука, `https://belayarod.ru/tg/rod-bot` |
| `BOT_DB_PATH` | база, `/var/lib/rodbot/bot.sqlite` |
| `PORT`, `HOST` | `4310`, `127.0.0.1` |

## Устройство

Node 22.13+, без `npm install`. Хранилище — встроенный `node:sqlite`, как у
Таро и рун.

- `server.mjs` — HTTP-сервер для вебхука (проверяет секрет) и рассылка
  серии раз в минуту.
- `logic.mjs` — команды, кнопки, заявки, пересылка ответов, серия. Сеть и
  часы передаются снаружи, поэтому логика проверяется тестами.
- `store.mjs` — таблицы `people`, `queue`, `admins`, `relays`.
- `telegram.mjs` — Bot API на `fetch`. При сетевом сбое запрос повторяется:
  с российского VPS Telegram доступен через раз.

Проверки: `npm run test:bot` (входит в `npm test`).

Бот хранит id чата, имя и @username человека, источник, выбранный запрос и
статус. Базу нужно бэкапить вместе с остальными данными сервера.
