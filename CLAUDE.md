# Сила Рода — контекст проекта

Общий сайт и бренд всех направлений **Екатерины Белой** (именно Екатерина, не
Катерина). Владелец — Владимир (vdoma88). Главный адрес — https://belayarod.ru.

## Состав

- `site/` — лендинг, статический HTML/CSS/JS. Заявки только через Telegram.
- `brand/` — общий бренд для лендинга и четырёх приложений. `PROJECTS` в
  `brand/sr-brand.js` — единственный список курсов.
- `infra/` — nginx, адреса, деплой, переезд школы.

Приложения — отдельные репозитории со своими стеками, базами и входом:
flame-app (Next.js + PostgreSQL, **рабочее, живые ученицы**), terapy (React/Vite +
Express/Prisma), tarot и runes-belaya (Node без пакетов + SQLite). Их код здесь
не хранится: бренд попадает к ним копией через `scripts/sync-brand.mjs`.

## Правила

- Строгий CSP везде: нет `style="…"`, `on*="…"`, inline-скриптов, `innerHTML` в бренде.
- Любое изменение `site/` или `brand/` — `npm test`, по возможности `npm run test:e2e`.
- Меняется бренд — поднять версию (package.json, `VERSION`, шапки файлов).
- Всё, что касается flame-app, делать осторожно: там идут занятия.
- Тексты для людей — по-русски, без канцелярита.
