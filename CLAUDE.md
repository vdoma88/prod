# Сила Рода — контекст проекта

Общий сайт и бренд всех направлений **Екатерины Белой** (именно Екатерина, не
Катерина). Владелец — Владимир (vdoma88). Главный адрес — https://belayarod.ru.

## Состав

- `site/` — лендинг, статический HTML/CSS/JS. Заявки только через Telegram.
- `brand/` — общий бренд для лендинга и четырёх приложений. `PROJECTS` в
  `brand/sr-brand.js` — единственный список курсов.
- `infra/` — nginx, адреса, деплой, переезд школы.

Приложения — отдельные репозитории со своими стеками, базами и входом:
flame-app (Next.js + PostgreSQL, **рабочее, живые ученицы**), terapy (React/Vite +
Express/Prisma), tarot и runes-belaya (Node без пакетов + SQLite). Их код здесь
не хранится: бренд попадает к ним копией через `scripts/sync-brand.mjs`.

## Дизайн

@brand/DESIGN.md

## Правила

- Строгий CSP везде: нет `style="…"`, `on*="…"`, inline-скриптов, `innerHTML` в бренде.
- Любое изменение `site/` или `brand/` — `npm test`, по возможности `npm run test:e2e`.
- Меняется бренд — поднять версию (package.json, `VERSION`, шапки файлов).
- Всё, что касается flame-app, делать осторожно: там идут занятия.
- Тексты для людей — по-русски, без канцелярита.

## Frontend references

Только при создании новой страницы или экрана, когда я говорю, что выглядит плохо,
или когда я называю один из этих сайтов. Мелкие правки — просто делай.

Главное правило: в проектах «Сила Рода» (prod, flame-app, terapy, tarot,
runes-belaya) дизайн уже задан — brand/sr-brand.js, tokens.css и стили
самого приложения, описан в brand/DESIGN.md. Внешний DESIGN.md в них не подключать. Референсы — только
там, где решение ещё не принято.

- Стиль нового проекта: один DESIGN.md с styles.refero.design или из
  VoltAgent/awesome-design-md — в корень проекта, @-импорт в его CLAUDE.md,
  дальше строго по нему. Никогда не смешивать несколько стилей.
- Компоненты (React/Tailwind — terapy, flame-app): сначала 21st.dev (через его
  MCP, если установлен; перед вызовом скажи, что ищешь — лимит бесплатный),
  потом component.gallery — как это сделано в зрелых дизайн-системах.
- Анимации: kinetics.colorion.co. На лендинге строгий CSP — никаких inline-стилей
  и скриптов, код адаптировать под это.
- Если результат всё равно выглядит не так: polish и distill из Impeccable
  (impeccable.style).

Если нужный MCP или навык не установлен — спроси, ставить ли, не имитируй.
Если не можешь прочитать страницу референса — попроси вставить содержимое,
не подставляй по памяти. Каждый раз говори, какой референс взял и что поменял.
