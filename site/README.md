# Лендинг belayarod.ru

Статический сайт «Сила Рода». Перенесён из `vdoma88/landos` и дальше развивается здесь.

## Источник и дальнейшая разработка

Базовый лендинг синхронизирован с `vdoma88/landos@7bd06b90367b9a33a5188463d4c9ee72f2c87aa8`.
Продакшен-версия расширена страницами «Мои курсы» и «Руны», прямым Telegram,
canonical/OG-адресами `belayarod.ru` и совместимостью с общей инфраструктурой.
Поэтому `site/` — источник истины; копировать `landos` поверх этой папки целиком нельзя.

## Страницы
- `index.html` — компактная главная: шесть карточек, раскрытие всех девяти направлений,
  фильтры и подробности без ухода со страницы. Без JavaScript все девять карточек
  видны и ведут на отдельные страницы направлений.
- `compact-home.css`, `compact-home.js` — оформление и поведение главной;
  заявки используют общее окно и `app.js`, изображения — локальные `assets/`.
- `courses.html` — «Мои курсы»: вход во все учебные кабинеты
- `therapy.html` — «Связь с Родом» (кабинет: rod.belayarod.ru)
- `candle-course.html` — свечные практики (школа: plamya.belayarod.ru)
- `tarot-course.html` — Карты Таро (taro.belayarod.ru)
- `runes.html` — Руны (runes.belayarod.ru)
- `mystery.html`, `game.html`, `offerings.html`, `massage.html`, `consultations.html` — направления без кабинета
- `404.html`
- `styles.css`, `app.js` (меню, FAQ, окно заявки, подбор формата и фильтр каталога на главной), `drum.js` (бубен на главной)
- телеметрия — общий `brand/sr-pulse.js` (приём и сводка — `accounts/pulse.mjs`, смотреть в админке belayarod.ru/account/ и в Telegram). Стоит на каждой странице раньше `app.js`
- `touch-icon.png` — иконка для экрана «Домой» на iPhone (180×180). Не `apple-touch-icon.png`: этот адрес nginx отправляет в школу
- `assets/` — изображения

`robots.txt` и `sitemap.xml` создаёт сборка (`scripts/build.mjs`).

## Ручное редактирование текстов без правки кода

Администратор открывает https://belayarod.ru/account/, входит под своей учётной записью
и нажимает «Редактировать тексты сайта». Откроется лендинг с рамками вокруг
редактируемых текстов. Нажмите на фрагмент, измените текст, затем
«Применить» (предпросмотр) → «Опубликовать» (сохранить для всех посетителей).
Кнопки «Отменить правки», «Исходный текст» и «Завершить» позволяют отказаться
от изменений. Список в панели переключает 11 страниц (в том числе главную и
отдельные направления). Интерфейс работает и на смартфоне.

Публикуемые фрагменты — **обычный текст**, не HTML: ссылки, картинки,
разметку и CSS редактор не меняет. Сложные интерактивные описания, которые
создаются JavaScript при раскрытии карточки, а также SEO-метатеги и
подписи в атрибутах HTML пока остаются в исходном коде.

Тексты хранятся в SQLite службой `accounts/`, а не в localStorage.
Любой посетитель получает опубликованные правки через
`GET /account/api/landing?page=index.html`; для публикации требуется
администраторская сессия и `POST /account/api/admin/landing`.
Версии предотвращают случайную перезапись чужих правок. Если API временно
недоступен, сайт показывает исходный текст из HTML.

**Деплой:** после обновления кода нужно пересобрать лендинг (`npm run build`)
и перезапустить службу `sr-accounts`, чтобы новый API и таблица SQLite
вступили в работу. Файл базы должен находиться на постоянном диске; при
восстановлении сервера сохраняйте его в резервной копии вместе с аккаунтами.

## Заявки — только Telegram
В `app.js`:

```js
const SITE_CONFIG = { telegramUsername: "", schoolUrl: "https://plamya.belayarod.ru/" };
```

`telegramUsername` — username без `@`. Пока поле пустое, кнопка открывает
Telegram Share с готовым текстом заявки. Список направлений в окне заявки
должен быть одинаковым на всех страницах — это проверяет `npm run check`.

`schoolUrl` нужен для иконки школы, которую ученицы добавили на телефон до
переезда: она открывает корень belayarod.ru, и `app.js` переводит такой запуск
в школу (подробно — `infra/MIGRATION.md`).

## CSP
Сайт работает под строгим CSP (`infra/nginx/snippets/sila-roda-headers.conf`):
никаких `style="…"`, `onclick="…"` и inline-скриптов. Исключение — JSON-LD
(`type="application/ld+json"`), браузер его не исполняет.
