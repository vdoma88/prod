# Нумерологическая матрица

Калькулятор по той же методике, что матрица в `vdoma88/terapy`. Страница
доступна по адресу `/matrix/` на основном сайте и не требует входа.
Дата рождения и имя рассчитываются в браузере; запись в базу и отправка данных
на сервер не нужны. Интерфейс и алгоритм взяты из проекта «Связь с Родом».

## Разработка

Из этого каталога: `npm ci`, `npm test`, `npm run build`. Сборка кладёт
готовые статические файлы в `../site/matrix/`, которые нужно закоммитить вместе
с изменённым исходным кодом: обычная сборка сайта не устанавливает пакеты.
При обновлении исходной матрицы нужно
синхронизировать код расчёта из `server/src/modules/numerology` и общие
компоненты матрицы из `client/src/pages/admin/client-card` репозитория `terapy`,
сохранив браузерный загрузчик словарей. Тест сверяет 1170 эталонных дат.
